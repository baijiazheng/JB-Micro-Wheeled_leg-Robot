# 上电联调方案 (Bring-up Plan)

> 板子打样回来之后，按这个顺序一步步点亮，每步都有预期结果和排查方法。
> 原则：**一次只验证一个子系统，坏在哪一步一目了然。**

---

| 项 | 内容 | 到位检查 |

| 驱动板 F103 | 打样 PCB + 焊接 | 目检无短路/虚焊 |
| 主控板 F407 | 打样 PCB + 焊接 | 同上 |

## 1. 上电前检查（不接电池）

1. **万用表测短路**：VIN ↔ GND、+5V ↔ GND、+3V3 ↔ GND 都不应短路
2. **目检焊接**：L6234 的 EP（散热焊盘）、AS5600/MPU6050 的引脚，重点查
3. **极性**：电池 XH2.54 正负极、SS34 防反接方向

---

## 2. 驱动板烧录 + 点灯验证

```bash
cd ~/JB-Micro-Wheeled_leg-Robot/firmware/driver_f103
make flash          # ST-Link 烧录 driver_f103.bin
```

**验证**：烧录成功（st-flash 报 success）。此步先不接电机/电池，只接 ST-Link。

---

## 3. 电源树验证（接电池）

1. 接 2S 电池，开开关
2. 测 **+5V**（MP2225 输出）≈ 5.0V
3. 测 **+3V3**（AMS1117 输出）≈ 3.3V
4. 测 **VIN** ≈ 电池电压（7.4~8.4V）

**排查**：无 5V → 查 MP2225（EN 上拉 100k、反馈 40.2k/5.49k、电感 4.7uH）；无 3.3V → 查 AMS1117。

---

## 4. FOC 开环验证（最关键的一步）

这是整个项目最难的一环，分两个小步：

### 4a. 单电机开环旋转
- 临时在 `control_loop_1khz()` 里把 Vq 设成固定值（如 0.3），注释掉平衡
- 烧录后，**单个电机应匀速旋转**，且用手拧能感到阻力（FOC 锁相）

### 4b. 编码器方向校准
- 读 AS5600 角度，手动转电机，确认角度连续变化（不跳 0/360）
- **方向不对** → 交换电机三相中任意两相，或反转 AS5600 方向

**关键坑**：
- 电机不转 → 查 L6234 EN 是否拉高、PWM 是否有输出（示波器/万用表测 PA8/PA9/PA10）
- 电机抖动不转 → FOC 电角度不对（极对数 7 是否正确、编码器零点）

---

## 5. 平衡验证（先不装腿）

1. 把驱动板**临时固定在车架重心处**，MPU6050 朝正确方向
2. 手持扶正，烧录完整固件
3. 手动扶正 → 松手 → **应能短暂自平衡**
4. 轻推 → 应能恢复（"踹一脚不倒"）

**排查**：
- 一上电就猛冲 → MPU6050 轴方向反了（俯仰角符号），改 `mpu6050.c` 里的 AXIS
- 缓慢倒下 → 平衡增益不对（先在 `balance.c` 调 pid_angle.kp）
- 高频抖动 → pid_gyro.kp 过大，或速度低通 alpha 太小

---

## 6. CAN 通信验证

1. 主控板烧录 `main_f407`，两块板 CANH/CANL 对接（各带 120Ω 终端）
2. 用逻辑分析仪或主控板串口看：主控每 10ms 发指令 0x100，驱动板回状态 0x200
3. **验证**：主控发 `linear_vel=100`，驱动板电机响应转动

**排查**：无通信 → 查波特率（500k）、终端电阻（两端各 120Ω）、CANH/CANL 是否接反。

---

## 7. 腿部验证

1. 接 STS3032 舵机（DATA 单线 + VIN 7.4V + GND）
2. 主控板发高度指令 → 舵机应同步运动
3. 验证跳跃：高度 80→40 快速切换，机器人应跳起

**排查**：舵机不动 → 查 1Mbps 波特率、DATA 线电平（需 5V 上拉）、舵机 ID（左 1 右 2）。

---

## 8. 整机联调（最终目标）

1. 装完整机械结构
2. 主控板发 `go` 指令 → 机器人站立
3. 发速度指令 → 前进/后退/转向
4. 发跳跃指令 → 跳跃

**验收标准**：
- ✅ 自平衡站稳 ≥ 1 分钟
- ✅ 踹一脚不倒
- ✅ 遥控前进/后退/转向
- ✅ CAN 双板通信正常
- ✅ 腿部高度/跳跃正常

---

## 9. 常见故障速查表

| 现象 | 可能原因 | 排查 |
|---|---|---|
| 上电无反应 | 电源树 | 测 5V/3.3V |
| 烧录失败 | ST-Link 未识别 | `st-info --probe`，udev 规则 |
| 电机抖动不转 | FOC 电角度错 | 查极对数/编码器零点 |
| 一上电猛冲 | IMU 方向反 | 改 MPU6050 轴 |
| CAN 无通信 | 终端电阻/波特率 | 两端 120Ω、500k |
| 舵机不动 | 电平/ID | DATA 5V 上拉、ID 1/2 |
| 平衡震荡 | 增益 | 调 pid_angle/gyro |
| 电机发烫 | L6234 假芯片 | 换正品 |

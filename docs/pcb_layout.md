# 双板 PCB 布局方案

> 参考板约 35×32mm（桌面级微机器人）。我们的板子参考这个尺度，
> 最终尺寸以 3D 机械模型为准。

---

## 一、驱动板 F103（约 40×35mm，2 层）

### 1. 功能分区（从左到右，按信号流）

```
┌─────────────────────────────────────────────┐
│ [电池XH2.54] [开关] [SS34防反接]  │  [CAN] [USB] │
│  电源区: MP2225 + AMS1117 + 电感   │  TJA1050 CH340│
│──────────────────────────────────────────────│
│            STM32F103C8T6 (中央)              │
│  去耦电容紧贴 MCU 电源脚                       │
│──────────────────────────────────────────────│
│  [L6234 #1]        [L6234 #2]   (边缘,贴电机) │
│  [AS5600 #1]       [AS5600 #2]  (伸向电机轴)  │
│         [MPU6050]  (重心处)                   │
└──────────────────────────────────────────────┘
```

### 2. 关键约束（最容易被忽略）

- **AS5600×2 必须正对电机轴磁铁**（距离 ~1mm）。电机在板子两侧时，
  AS5600 要放板边缘、甚至**伸出小耳朵**伸到电机轴正上方。
  若装不下 → 改成两块小卫星板（GH1.25 4P 线连回），这是原项目的做法。
- **MPU6050 放整车重心**：先粗装机械，用铅笔记下重心在板上的投影点，把 IMU 放那。
- **L6234 靠板边**：散热焊盘(EP)打孔/铺铜到地，帮助散热。

### 3. 层策略（2 层）

- **底层 = 完整地平面**（铺铜，尽量不割断）
- **顶层 = 信号 + 元件**
- 电源线（VIN/+5V/+3V3）走**宽线**（≥0.5mm），电机轨（VIN→L6234 Vs）**≥1mm**

### 4. 走线要点

| 信号 | 要求 |
|---|---|
| L6234 三相 PWM | 短、粗（≥0.3mm），三根尽量等长 |
| CAN 差分对 | CANH/CANL **并行走**，尽量近，别跨电源 |
| I2C（编码器/IMU） | 上拉电阻**靠近 MCU 侧**，走线别绕大圈 |
| 电池→L6234 电机轨 | 加粗，与逻辑轨**星型分开**（单点接地） |
| 去耦电容 | 每个 IC 电源脚 0.1uF，**紧贴**引脚 |

## 二、主控板 F407（约 40×35mm，2 层）

```
┌──────────────────────────────┐
│ [电池] [开关] [SS34] │ [CAN] [USB] │
│  MP2225 + AMS1117    │ TJA1050 CH340│
│──────────────────────────────│
│        STM32F407VET6          │
│──────────────────────────────│
│  [STS3032舵机接口] (DATA/VIN/GND)│
└──────────────────────────────┘
```

- 舵机接口放板边，DATA 线加 **5V 上拉电阻**（舵机是 5V 逻辑）
- 其余同驱动板（地平面、差分对、去耦）

---

## 三、两板之间的机械/电气连接

- **电源**：电池 + 电源树放**驱动板**（电机电流大，就近供电）；
  主控板通过**堆叠排针/排母**从驱动板取 5V/3.3V（减少一套电源电路）。
- **CAN**：两板各一根 2P 排线（CANH/CANL 对绞），两端 120Ω。
- **堆叠方式**：驱动板在下（贴电机），主控板在上（铜柱 M2×3 支撑），
  正好符合"两层板子"的设计。

## 四、打样参数（嘉立创下单参考）

| 项 | 值 |
|---|---|
| 层数 | 2 层 |
| 板厚 | 1.6mm |
| 铜厚 | 1oz（电机轨可 2oz） |
| 最小线宽/间距 | 6mil / 6mil（嘉立创常规工艺） |
| 表面处理 | HASL 或沉金 |
| 数量 | 各 5 片（打样） |

---

## 五、布局完成后的检查清单

- [ ] AS5600 正对电机轴磁铁（距离 <1.5mm）
- [ ] MPU6050 在重心投影点
- [ ] L6234 EP 散热焊盘接地
- [ ] 底层地平面完整（无大割断）
- [ ] CAN 差分对并行走、两端 120Ω
- [ ] 电机轨与逻辑轨星型接地
- [ ] 每个 IC 去耦电容紧贴
- [ ] 电池极性 + SS34 方向正确

# 双板原理图设计蓝图

> 本文是画 KiCad 原理图的直接依据。电路参考原项目 4 块板，重新整合成 2 块板。
> 最终引脚以 CubeMX 配置为准（避免外设冲突），本文给出推荐分配。

---

## 一、电源树（两板共用同一套）

```
电池 2S (7.4V, XH2.54) ─[开关]─ VIN
  ├─ L6234×2 的 Vs (电机轨, 直连)
  └─ MP2225GJ-Z 降压 → 5V
       ├─ STS3032 舵机 (主控板)
       └─ AMS1117-3.3 → 3.3V (MCU/AS5600/MPU6050/CAN)
```

**关键器件与值（照搬参考）**：
| 器件 | 值/型号 | 备注 |
|---|---|---|
| 降压 | MP2225GJ-Z | VIN→5V，L1=4.7uH，反馈 R8=40.2k / R19=5.49k |
| LDO | AMS1117-3.3 | 5V→3.3V |
| 输入电容 | 22uF + 0.1uF | MP2225 输入 |
| 输出电容 | 22uF×2 + 0.1uF | MP2225 输出 |
| 电机轨电解 | 100uF + 100nF ×2 | L6234 Vs 旁路 |

## 二、驱动板 F103C8T6（运动控制层）

### 引脚分配

| 外设 | 引脚 | 说明 |
|---|---|---|
| 电机1 PWM (TIM1) | PA8/PA9/PA10 (CH1/2/3) | 3 相 → L6234 IN1/2/3 |
| 电机2 PWM (TIM3) | PA6/PA7/PB0 (CH1/2/3) | 3 相 → L6234 IN1/2/3 |
| 电机使能 | PB1 (EN1), PB12 (EN2) | L6234 EN 引脚 |
| I2C1 (编码器1) | PB6(SCL)/PB7(SDA) | AS5600 #1 (地址 0x36) |
| I2C2 (编码器2+IMU) | PB10(SCL)/PB11(SDA) | AS5600 #2 + MPU6050 |
| CAN1 | PA11(RX)/PA12(TX) | 经 TJA1050/SN65HVD230 |
| 调试串口 USART2 | PA2(TX)/PA3(RX) | 经 CH340C |
| SWD | PA13/PA14 | ST-Link 烧录 |
| 电池 ADC | PA0 | 分压采样电池电压 |

### 电路块

1. **L6234 ×2（电机驱动）**：IN1/2/3 接 PWM，EN 接使能；Vs 接 VIN(7.4V)，100uF+100nF 旁路；Vcp/Vboot 接充电泵/自举电容（参考值 1uF/220nF/10nF）；SENSE1/2 接地（电压模式无电流采样）。
2. **AS5600 ×2**：VDD3V3 供电，I2C 上拉 4.7k，100nF+1uF 去耦；**必须分两条 I2C**（固定地址 0x36）。
3. **MPU6050**：I2C2 与编码器2 共线，0.1uF 去耦。
4. **CAN 收发器**：TJA1050/SN65HVD230，CANH/CANL 差分 + 120Ω 终端。
5. **CH340C**：USB→USART2，调试串口。
6. **去耦**：F103 每个电源脚 100nF。

## 三、主控板 F407VET6（应用层）

### 引脚分配

| 外设 | 引脚 | 说明 |
|---|---|---|
| CAN1 | PB8(RX)/PB9(TX) | 经收发器，接驱动板 |
| 舵机总线 USART6 | PC6(TX)/PC7(RX) | STS3032 单线半双工 |
| 调试串口 USART1 | PA9/PA10 | 经 CH340C |
| SWD | PA13/PA14 | ST-Link |
| 按键/LED | 若干 GPIO | 用户交互 |

### 电路块

1. **舵机接口（STS3032 ×2）**：单线半双工——STM32 USART6 开 **半双工模式**（HDSEL），DATA 线上加 **5V 上拉**（SS8550 或直接 10k 上拉到 5V），舵机供电 VIN(7.4V)。相比参考的 SN74LVC1G125/126 三态门方案更简洁。
2. **CAN 收发器**：同上，120Ω 终端。
3. **CH340C + USB**：调试。
4. **电源**：同驱动板（MP2225+AMS1117），或从驱动板取 5V/3.3V（堆叠连接器）。

---

## 四、板间连接

- **CAN**：两板各一个 TJA1050，CANH/CANL 对绞线，两端 120Ω。
- **电源**：电池在主控板还是驱动板？（建议驱动板承载电池+电源树，主控板经堆叠连接器取 5V/3.3V，减少重复电源电路）

---

## 五、⚠️ 机械约束（PCB 布局时必须解决）

原项目 4 块板里 **EncoderPCB/IMUPCB 是独立的**，因为：
- **AS5600 必须正对电机轴端磁铁**（直径 4mm 磁铁粘轴上，距离 ~1mm）
- **MPU6050 要放在整车重心（CoM）**，平衡才准

**我们的处理方案**（二选一，PCB 布局时结合 3D 模型定）：
- **方案 A**：AS5600×2 + MPU6050 集成到驱动板，驱动板设计成"骑跨在电机上方"的位置（既贴近编码器磁铁，又在 CoM 附近）
- **方案 B**：AS5600×2 + MPU6050 保留为两块小"卫星板"（同参考），用 GH1.25 4P 线连到驱动板，其余全部集成

> 建议先按 **方案 A** 画（把 AS5600/MPU6050 放驱动板上），若机械装不下再切 B。

## 六、关键风险清单（画图时逐条核对）

- [ ] L6234 假芯片多 → 立创商城自营
- [ ] AS5600 固定 0x36 → 两条 I2C 不能混
- [ ] F103 PA9/PA10 = TIM1 和 USART1 冲突 → 调试口用 USART2(PA2/PA3)
- [ ] CAN 两端各一个 120Ω 终端（不是 2 个 120Ω 并联在一端）
- [ ] 舵机 7.4V 供电，DATA 线 5V 逻辑 → STM32 3.3V 半双工需电平匹配（上拉 5V）
- [ ] MPU6050/AS5600 的 I2C 上拉：模块自带时板上可省，需确认

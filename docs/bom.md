## 三、关键风险提示

- **L6234 假芯片多**（原作者提醒），立创商城自营/正规渠道购买
- **AS5600 固定地址 0x36** → 两个必须分两条 I2C 总线（F103 正好 2 个）
- **F103 20KB RAM 偏紧**：FOC×2 + 平衡 + MPU6050，若不够升级 F303CC（40KB RAM，也有 CAN）
- 立创商城 LCSC 料号将在**画原理图时**逐一定下（嘉立创EDA 放置元件自动带料号）

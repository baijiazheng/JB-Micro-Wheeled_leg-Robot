# 板级规格书（双板统一定义）

> 这是"属于我们自己板子"的规格。两块板同尺寸 → 可堆叠 → 即插即用。
> 定稿日期 2026-09-13

---

## 一、机械规格

| 项 | 值 | 说明 |
|---|---|---|
| **外形尺寸** | **50 × 50 mm** | 两板统一，圆角 R2 |
| 层数 | 2 层 | 顶层信号 + 底层整片 GND |
| 板厚 | 1.6 mm | 嘉立创标准 |
| 铜厚 | 1 oz（电机轨可 2 oz） | |
| 安装孔 | **4× M2.5**，坐标 (3,3)(47,3)(3,47)(47,47) | 原点取板左下角 |
| 堆叠 | 驱动板在下、主控板在上，M2.5 铜柱 8mm | 见"五、堆叠" |

**尺寸依据**：53 个元件的封装占用面积 ≈ 1140 mm²（其中 2× L6234 占 352mm²），
50×50=2500mm² → 元件密度 46%，留足布线空间。

## 三、硬约束（违反则板子废）

| # | 约束 | 原因 |
|---|---|---|
| 1 | **AS5600 (U4/U5) 必须能正对电机轴端磁铁**（间距 ~1mm） | 磁编码器测轴端磁场；若机械上够不到 → 改成小卫星板用 GH1.25 线连 |
| 2 | **MPU6050 (U6) 放整车重心投影点** | 否则平衡算法读数有系统性偏差 |
| 3 | **L6234 (U2/U3) 靠板边**，散热焊盘(EP)大铺铜 + 过孔 | 线性驱动发热 |
| 4 | **U1 每个电源脚旁 0.1uF 紧贴** | 去耦 |
| 5 | **电机轨（VIN→L6234 Vs）加粗 ≥1mm** | 电机电流 |
| 6 | **底层整片铺 GND**，不割断 | 完整地平面 |

## 四、焊接约束（锡膏 + 加热台）★

**加热台只能焊一面**（背面元件会被压住/位移），所以：

- ✅ **所有贴片元件（SMD）放同一面**（建议全放**顶层**）
- ✅ 插件元件（排针 J2/J3/J4、电池座 J1、开关 SW1、USB J5）放**底层**，或顶层最后手焊
- ✅ 一次回流焊完成所有 SMD → 再手焊插件

**布局时必须检查**：不要出现"顶层和底层都有 SMD"的情况。

## 五、堆叠（即插即用）

```
        ┌──────────────┐
        │  主控板 F407  │  ← 上层
        └──────────────┘
           ↑ ↑    ↑ ↑
        M2.5 铜柱 ×4 (8mm)
           ↓ ↓    ↓ ↓
        ┌──────────────┐
        │  驱动板 F103  │  ← 下层（贴电机）
        └──────────────┘
```

- 板间连接：**2×4 排针/排母**（含 CAN H/L + 5V + 3V3 + GND）
- 两板 50×50、四角孔位一致 → 随时拆装、换板不换机械

## 六、布线规则

| 规则 | 值 |
|---|---|
| 最小线宽/间距 | 6 mil / 6 mil |
| 电源线 | ≥ 0.5 mm |
| 电机轨 | ≥ 1.0 mm |
| CAN 差分对（CANH/CANL） | 并排走，间距恒定，尽量短 |
| L6234 三相 PWM | 短、粗（≥0.3mm），三根尽量等长 |
| 铺铜 | 底层 GND 整片；顶层可局部铺 |
| 过孔 | 0.3/0.6mm（散热焊盘多打过孔） |

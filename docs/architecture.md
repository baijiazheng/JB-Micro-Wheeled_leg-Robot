# JB-Micro-Wheeled_leg-Robot — STM32 双板架构设计

> 目标：把 [Micro-Wheeled_leg-Robot](https://gitee.com/lavine/Micro-Wheeled_leg-Robot)（ESP32 单板）复刻为
> **STM32 双板 + CAN** 版本，元器件直接集成，FOC 从零用 HAL 实现。
> 本文件是 Phase 1 的唯一权威设计文档，后续原理图/固件都以此为准。

## 1. 参考项目分析（已读透）

### 1.1 硬件四件套（我们要集成到两板上）

| 功能 | 器件 | 数量 | 关键点 |
|---|---|---|---|
| 无刷驱动 | **L6234PD013TR** | 2 | 三相 BLDC 驱动，电压模式 FOC（无电流采样） |
| 编码器 | **AS5600-ASOM** | 2 | I2C，**固定地址 0x36 → 必须两条 I2C 总线** |
| 姿态 | **MPU6050** | 1 | I2C，0x68，与右侧编码器共一条总线 |
| 腿 | **STS3032** | 2 | 单线半双工串口舵机，1Mbps，7.4V 供电 |
| 降压 | **MP2225GJ-Z** | 1 | 电池 7.4V → 5V（开关降压） |
| LDO | **AMS1117-3.3** | 1 | 5V → 3.3V |
| USB串口 | **CH340C** | 1 | 调试/烧录 |
| 舵机电平 | SN74LVC1G125/126 + SS8550 | — | 参考用外部三态门做单线合并，**STM32 可原生替代** |

### 1.2 参考电源树

```
电池 2S (7.4V) ─┬─ L6234×2 (Vs) ── 无刷电机 ×2   （电机轨）
                └─ MP2225 降压 → 5V ─┬─ STS3032 舵机 (逻辑 5V)
                                     └─ AMS1117 → 3.3V ── ESP32/AS5600/MPU6050
```

### 1.3 参考控制算法（固件已读透）

- **LQR 平衡**拆成 4 个 PID：`U = k1·(angle-零点) + k2·gyro + k3·(distance-零点) + k4·speed`
- **yaw 转向环**：yaw 角度 + yaw 角速度 PID
- **腿部**：高度控制 + roll 平衡（腿左右倾补偿）+ 跳跃（舵机快速蹲→蹬）
- **轮子离地检测**：转速/角加速度突变 → 落地后自动恢复
- **电机输出**：`motor.target = -0.5·(LQR_u ± YAW_output)`，扭矩=电压模式

## 2. 我们的双板架构

**核心原则：平衡环（IMU→FOC）必须在一颗芯片内闭环，CAN 不进实时回路。**

```
┌─ 驱动板 STM32F103C8T6（运动控制层，~1kHz 实时）────────────┐
│  L6234×2 (FOC) + AS5600×2 (I2C) + MPU6050 (I2C)          │
│  跑: FOC(自写) + LQR平衡 + yaw + roll 计算                │
│  CAN 从机: 收 目标速度/高度/跳跃/模式                       │
│            发 姿态/转速/位移/电量/状态                     │
└──────────────────────────────────────────────────────────┘
                    ↑ CAN (500kbps, 只传指令/状态)
┌─ 主控板 STM32F407VET6（应用层）───────────────────────────┐
│  STS3032×2 (半双工 USART) + CAN 主机                       │
│  跑: 腿部控制 + 状态机 + (Phase2: ESP32 网页桥接)          │
└──────────────────────────────────────────────────────────┘
```

## 3. 引脚分配

### 3.1 驱动板 STM32F103C8T6

| 外设 | 引脚 | 说明 |
|---|---|---|
| FOC PWM 电机1 | PA8/PA9/PA10 (TIM1_CH1/2/3) | 三相上桥/下桥 PWM |
| FOC PWM 电机2 | PA6/PA7/PB0 (TIM3_CH1/2/3) | 三相 PWM |
| L6234 使能 ×2 | PB12, PB13 | EN 引脚 |
| I2C1 (编码器1) | PB6/PB7 | AS5600 #1 (地址 0x36) |
| I2C2 (编码器2+IMU) | PB10/PB11 | AS5600 #2 + MPU6050 |
| CAN | PA11/PA12 | 经 TJA1050/SN65HVD230 收发器 |
| USART1 调试 | PA9/PA10 | CH340（注：与 TIM1 PWM 冲突，改用 USART2 PA2/PA3） |
| SWD | PA13/PA14 | 烧录调试 |

> ⚠️ 注意：F103 的 PA9/PA10 同时是 TIM1_CH2/CH3 和 USART1，冲突。
> 最终 PWM/串口引脚以 CubeMX 分配为准，避免冲突。

### 3.2 主控板 STM32F407VET6

| 外设 | 引脚 | 说明 |
|---|---|---|
| 舵机总线 | 半双工 USART（如 PD5/PD6） | STS3032 单线，1Mbps |
| CAN1 | PB8/PB9 (或 PD0/PD1) | 经收发器 |
| USART1 调试 | PA9/PA10 | CH340 |
| SWD | PA13/PA14 | 烧录调试 |
| 预留 | 多个 GPIO | 未来：按键/LED/ESP32 桥接 |

## 4. CAN 协议（v1 草图）

- 速率 **500kbps**，标准帧 11 位 ID，两端 120Ω 终端
- **主→从（指令帧，ID 0x100~）**：目标线速度、角速度、高度、跳跃触发、模式、急停
- **从→主（状态帧，ID 0x200~）**：姿态角、轮速、位移、电池电压、失控标志
- 周期：状态帧 200Hz，指令帧按需（50Hz）

## 5. FOC 从零实现路线（HAL）

用 b 方案（HAL 手写），学习顺序：

1. **PWM 三相生成**（TIM1/TIM3 互补 PWM，6 通道）
2. **Clarke 变换**（三相电流 → αβ，但电压模式先跳过电流采样，用电压 αβ 直接算）
3. **Park 变换 + 逆变换**（转子角度来自 AS5600）
4. **SVPWM**（空间矢量调制，替代 SPWM）
5. **开环电压 FOC**：给定 Iq 目标 → 逆 Park → SVPWM → 电机转
6. **闭环**：先速度环（编码器微分），再（可选）电流环（加采样电阻 + ADC）
7. **移植参考的 LQR 平衡环**到 F103

> 参考用的就是**电压模式 FOC**（`torque_controller = voltage`，无电流采样），
> 我们照做，先跑通，电流环作为进阶。
